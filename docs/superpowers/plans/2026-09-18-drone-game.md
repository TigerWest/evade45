# DEAD AIR 3D Implementation Plan

**Goal:** 지상 1인칭 시점에서 도보·오토바이·경장갑차로 드론을 피하며 추적 압박을 체감하는 웹게임.

**Architecture:** Three.js WebGL 렌더러, 독립된 이동·충돌 엔진, Web Audio 방향음, HTML 오버레이. 2D 초안을 사용자의 정정에 따라 3D로 교체했다.

**Tech Stack:** Three.js 0.186.0, browser ES modules, Web Audio, Node test runner.

## Requirements

- [x] 실시간 3D 지형, 건물, 드론과 지상 1인칭 시야
- [x] 도보 이동, 오토바이 조향·가속, 경장갑차 관성·추가 방호
- [x] 마우스 시선, 포인터 잠금 및 드래그 대안, 키보드와 모바일 입력
- [x] 45초 생존과 3종 난이도
- [x] 상공 추적, 조준, 궤적이 고정되는 급강하, 3D 충돌
- [x] 방향·거리별 모터 소리, 발소리·호흡·엔진·피격 효과음
- [x] 시작, 일시정지, 재개, 실패, 성공, 다시 시도
- [x] 모션 줄이기와 WebGL 오류 화면
- [x] 게임 엔진 테스트, JavaScript 구문 검사, 정적 빌드
- [x] 브라우저에서 3D 실행과 차량 선택·일시정지 확인
